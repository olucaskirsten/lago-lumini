# Lago Lumini — Landing Page

Landing page desenvolvida em HTML, CSS e JavaScript puro.

## Estrutura

- `index.html`
- `css/style.css`
- `js/script.js`
- `assets/images/`
- `assets/lots/`
- `assets/logo/`
- `assets/video/`

## Como abrir

Abra `index.html` diretamente no navegador ou rode um servidor local, por exemplo:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.
